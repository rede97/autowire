# TB 顶层封装（`aw-tb-mod` + `type="raw"` + include 钩子）

> 状态：已落地。本文是 TB 顶层（testbench top）封装的契约；骨架与总流程见 [`html.md`](./html.md)。

## 0. DE / DV 分工与产出目录

| 角色 | 作者 SoT | toml 登记 | dump 产物目录 |
|---|---|---|---|
| **DE**（设计封装） | `connect/*.html`，根为 `aw-mod` | `[connect.<id>]` | **`connect_dir`**（默认 `gen/connect`） |
| **DV**（验证顶） | `sim/*.html`，根为 `aw-tb-mod` | **`[sim.<id>]`**（独立节，不塞进 connect 列表） | **`sim_dir`**（默认 `gen/sim`） |
| **插件生成器** | 插件声明页 / `[plugin.<id>]` | 非 connect / 非 sim | **`plugins_dir`**（默认 `gen/plugins`），其下再按 **plugin id** 分子目录 |

纪律：

1. **禁止**把 TB 顶与 DE 包装写在同一 HTML 文件。
2. **禁止**把 `[sim.<id>] html=` 指到 `connect/` 树（应当落在 `sim/` 或 DV 约定目录）。
3. **禁止**把 `[connect.<id>]` 指到以 `aw-tb-mod` 为根的页；**禁止** `[sim.<id>]` 以 `aw-mod` 为根。
4. 产物目录在 `[workspace.dump]` 三分（见 [`../workspace/toml.md`](../workspace/toml.md)）。

```toml
[workspace.dump]
connect_dir = "gen/connect"   # DE：aw-mod 单元
sim_dir     = "gen/sim"       # DV：aw-tb-mod 单元
plugins_dir = "gen/plugins"   # 类型 A 插件；例如 gen/plugins/wishbone/

[connect.soc_top]
html = "sot/connect/soc_top.html"
deps = ["sha256wb"]

[sim.soc_tb]
html = "sim/soc_tb.html"
deps = ["soc_top"]            # 可依赖 connect 单元 id；sim 单元不被 connect 例化
```

`[sim.<id>]` 的 `deps` 规则与 connect 相同（缺边 error / 多余 warn / 无环）；sim 单元是 DAG **汇点**（可依赖 connect，**禁止**被 connect / 其它 sim 当作可例化包装源——不进 `.autowire/connect/` 抽象接口快照）。

## 1. 三项机制

### 1.1 `<aw-tb-mod>`（TB 顶层封装）

等价于 `aw-mod` + 一组 TB 默认值，但**无嵌套包装树**：可有 `aw-content` / `aw-render`；**禁止** `aw-submods`。模板 / rewrite / 钩子照常。与 identity 兼容；**不导出**、网默认 **logic**。

| 面 | 与 aw-mod 的差异 |
|---|---|
| 导出 | 不导出任何端口；写 `aw-ports` → **报错** |
| 信号声明 | 自动声明的网默认 **`logic`** |
| dump 头部 | `module name;`（无端口列表） |
| dump 目录 | 写入 **`sim_dir`**，不是 `connect_dir` |
| include | `body-pre-include` / `body-post-include`（§1.2） |
| 参数 | **禁止 `aw-params`**；只允许 `aw-localparams` |
| 位置 | 仅 `[sim.<id>]` 页的顶层；禁 submods / 禁被例化 / 禁 `aw-tb-mod@deps`；不进 connect XML sidecar |

### 1.2 模块体内 include 钩子（env / bind vs stim）

| 属性 | dump 落点 | 典型用途 |
|---|---|---|
| `body-pre-include` | `module name;` 之后、信号/例化之前 | 验证环境、`bind`、checker |
| `body-post-include` | 例化之后、`endmodule` 之前 | stimulus、plusargs、仿真控制 |

```html
<aw-tb-mod
  name="tb_soc"
  body-pre-include="tb_env_setup.svh"
  body-post-include="tb_sim.svh"
>
```

- `body-pre-include` 是 UVM / DV 环境入口（import package、声明 vif / interface 实例），落在 dump 网线声明 **之前**，所以 **禁止**驱动或引用 dump 出的网线；时钟 / 复位 / pad 驱动放 `body-post-include`（先用后声明，仿真器报错）。
- 属性值按空白切分，可列多个文件，按序各出一行 `` `include ``（demo：pre `tb_env_setup.svh`；post `tb_board.svh tb_sim.svh`）。
- 属性值**原样**写入 `` `include "…" ``；**不**复制、**不**改路径。
- 路径解析归 **DV filelist / `+incdir`**；check **不做**存在性检查。
- 仅 `aw-tb-mod`；`aw-mod` 上出现 → check **报错**。

### 1.3 `type="raw"`（原样裸传）

| 项 | 规则 |
|---|---|
| 写法 | `<aw-connect port="x" type="raw" to="…">` |
| 语义 | 先 `${…}`，再原样进 `.port(<text>)`；不分类、不建网、不查方向/维 |
| 互斥 | part/维/nettype → 报错；rewrite 产 raw → 报错 |
| 作用域 | 仅 `aw-tb-mod`；`aw-mod` 中 → check 报错 |

**必须 `${…}`**：代入后不进 `aw-signals`。

## 2. dump 输出形态（示例）

```systemverilog
// Generated by autowire dump (sim unit "soc_tb"). Do not edit: SoT is sim/soc_tb.html.
module tb_soc;
`include "tb_env_setup.svh"
	logic clk;
	logic [31:0] irq_bus;
	soc_top u_dut (
		.clk    (clk),
		.irq    (irq_bus),
		.trap   ()
	);
`include "tb_sim.svh"
endmodule
```

可运行范例：[`demo/soc/sim/soc_tb.html`](../../demo/soc/sim/soc_tb.html)、[`07-author-tb-top.html`](../examples/connect/07-author-tb-top.html)。
