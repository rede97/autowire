dtsim — simulation runner (docs/dtsim/README.md)

Layout
  <project>/               RTL design dir; filelists and ${workspace} resolve here
  <project>/dt/            testbench code
  <project>/dt/config/     dtsim.config.ts (TypeScript), filelists, hook modules
  <project>/dt/simout/     outputs (git-ignored)

Entry
  autowire dtsim <cmd>     same as: ln -s autowire.js dtsim; ./dtsim <cmd>
  dev: bun index.ts dtsim <cmd>

Commands
  run <case>               compile + simulate (--compile-only, --sim-only, --interactive)
  regr [group]             regression, default group all
  plan [group]             compile-group plan, no run
  list | groups            cases / groups
  results --dir <dir>      read or --recheck results
  env --case <id>          environment a case would get (--phase, --show-values)
  common: --config <file> (default dt/config/dtsim.config.ts upward from CWD),
          -s, --num-seeds, -d <label>, -v, --plain, --cov, --no-wave
  output: plans, tables and result trees on stdout; progress on stderr
          (live panel on a TTY, one line per event with --plain or a pipe).
          run: "[spinner|status] [elapsed] [phase] <log> <size>" lines, the
          submitted command in a box titled cmd, size + last line of the
          compile and sim logs ("-" until a log is on disk). run -v on a TTY
          also prints the running log's new lines above the panel. No TTY:
          concise start / end lines for compile, sim and grade only.
          regr: Regression table, plan tree (compile <name>, its args, then
          its sims and their args), live build trees on a TTY, a status line
          per finished compile / sim with log path and size, then results
          and a Summary table. Builds are named by SimTool.buildName
          (default first case id); dirs are compile_<name>

Rules
  Filelist entries are relative to the project root (nested -f too); dtsim
  writes an absolute flat copy into each compile dir.
  Placeholders are ${name}: ${workspace} ${verify} ${output_dir} ${case} ${seed}
  ${tool}. Paths (output, filelist, cases, hooks) also take shell vars (${HOME});
  unknown names fail. Workspace({ output }) moves dt/simout.
  hooks: { preCompile: fn | [fn, ...], ... } TypeScript callbacks; one
  HookContext for every stage (dir, log, seed, status, caseOpts, env,
  expand, resolvePath, sh). ctx.sh runs bash with the phase env; a throw fails.
  Cases: Case(name, opts); c.SubCase(suffix, opts | (parent) => opts) derives
  <id>.<suffix> at any depth; export only top-level cases. Function opts run
  only when that case is used. c.descendants() lists the subtree.
  Group(name, [caseObj, "id", "base.*.cosim", "base.**"]): * = one segment,
  ** = any depth.
  Hook stages: preCompile postCompile preSim postSim onResult;
  demo/dtsim shows all five, demo/soc preCompile + preSim.
  Graders decide each seed's status from sim.log, never the exit code.
  Graders are values: Workspace({ grader }) (default DefaultGrader()), case
  grader overrides and is inherited. DefaultGrader({ pass, error, expect,
  waive: [WaiveRule(...)], uvm }) checks keywords and the UVM report;
  g.extend({...}) appends. Custom: defineGrader({ name, grade(ctx) }) returns
  a Status or { status, note, details, highlight }. Logs stream in a worker
  (scanLog / streamLines). results --recheck reuses the grader.
  Children get only passthrough-listed env vars.
  Backends are values: tool: VcsTool({ ntbOpts, flags }) | VerilatorTool({ top,
  mdir, main }) | defineTool({ name, ... }); case toolOptions override them.
  Launchers: task.launcher: LocalLauncher() (default) | LsfLauncher({ queue,
  args }) (bsub -I) | SlurmLauncher(...) (srun --pty) | defineLauncher({ name,
  passthrough, wrap }). DTSIM_TASK_TYPE=local|lsf|slurm swaps in a built-in;
  DTSIM_TASK_QUEUE sets ctx.queue.

Demos
  demo/dtsim/run.sh <args>          fake tools in demo/dtsim/dt/bin
  demo/soc/dt/verilator/run.sh      Verilator smokes (--regfile --sd --tb-mod --sv-reg)
  demo/soc/dt/vcs/run.sh [case]     VCS tb_soc smokes
  demo/hbm/dt/vcs/run.sh [test...]  VCS + UVM-1.2 regression
