Write-back is connect run, not a web POST.

  autowire connect run [unit]

Reads aw-render after check and elaborate. Writes .sv and, for connect units,
the <id>.xml snapshot, deps first. Connect units write <module>.sv in connect_dir;
a [sim.<id>] unit writes sim_dir/<id>.sv (the module keeps its aw-tb-mod name).
The web session does not call this and does not write.
